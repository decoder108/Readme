# Hi there, I'm Priyanka Singh!

### 🧬 Bioinformatics • Machine Learning • Biomedical AI

I'm a **PhD Candidate in Informatics at the University of Iowa**, exploring how computational methods can help us better understand complex biological systems.

My work brings together **machine learning, genomics, microbiome research, and clinical informatics** to address meaningful challenges in biomedical science.

- 🤖 **Biomedical AI** — Reliable and interpretable machine learning for biological and clinical data.
- 🔗 **Clinical Informatics** — Connecting biomedical information across healthcare systems.
